# 官方账号与本地回复

管理页的“官方账号”提供米游社及 HoYoLAB 官方窗口，登录方式以官网实际提供的选项为准。米游社已观察到扫码、短信、密码；HoYoLAB 已观察到账号密码及 Google、Apple、Facebook、X。第三方服务可能限制嵌入式浏览器，不能保证所有授权方式均可用。

## 操作与区服

登录后回到评论列表，点击主评论或具体子回复旁的“回复”。编辑器显示来源、区服、对象原文、社区账号，以及自己的发送角色名和 UID。目标区服唯一角色自动选中，自己发的内容优先选择所属角色；同服有多个且无法唯一确定时自行选择。输入文本后明确点击发送，打开窗口或登录不会自动发言。

国服与外服会话独立，官服／B服及各外服角色分别校验。没有目标服角色时不能借用其他服。社区 aid／昵称与游戏 UID／角色名不同，不要求相同。更换账号后重新检测，草稿按社区账号、游戏角色和目标隔离，存于当前浏览器。原生窗口“检查原神角色”是辅助诊断，实际发言请在收集器内点击目标的回复按钮；官方决定最终发言权限。

本人子回复的“管理 / 删除”打开管理操作，进入独立管理窗口，验证归属后启用删除按钮，确认后删除。不能删除别人。主评价删除未提供，目前官方核实到主评价编辑入口，不用空白编辑替代删除。本人行删除后保留其他人的后续回复，已有便签保留手写备注和删除历史。

确认已发送但本地保存未完成时，刷新原串，不要再次发送。发送结果不明时锁住再次发送，保留原尝试编号，先刷新核对回执，不自动切换代理重发。删除结果不明时由后台自动只读核对；确认缺席后自动清理本地，达到上限才提示继续核对，不再次发送删除。更多恢复步骤见 [AI-INTEGRATION.md](AI-INTEGRATION.md)。

## 会话、依赖与升级

需要 Windows x64、.NET Framework 4.6.2+ 和 Microsoft Edge WebView2 Runtime。缺少登录组件不影响公开评论采集。Microsoft.Web.WebView2 SDK 为 1.0.4314.35，保留 [LICENSE](../account-login/WebView2-LICENSE.txt) 和 [NOTICE](../account-login/WebView2-NOTICE.txt)，不由项目 MIT 许可证替代。

会话位于当前用户的 %LOCALAPPDATA%/MiliastraCommentCollector/LoginProbe/cn 和 os，更换工具目录不会清空，不要分享。原生桥接程序内部使用该专用配置的限域 Cookie，仅发往固定官方 HTTPS 主机；Cookie 不返回 Node、HTTP 或 AI，不写入项目配置／数据／日志，不读取日常 Chrome／Edge 配置。只在官方窗口输入密码、验证码或扫码。普通采集的可选 config/cookie.txt 是此前独立的手动设置，不是登录桥接导出功能。

config/reply-attempts.json 保存发送／删除的上下文、UID、正文摘要和回执，不含 Cookie 或明文正文，防止重启后重发。升级随完整 config/ 保留，不要删除该文件或将个人配置上传 GitHub。账号窗口或发言正在处理时暂缓服务自动退出。回退前等待操作结束并关闭后台及官方窗口，回退不等于退出官网账号。

## 验证范围与集成

米游社已实际登录并自动匹配官服角色，一次获准测试回复已通过官方读回确认。HoYoLAB 尚未完成真实登录后的发言验证；已对一条用户删除记录做官方只读缺席核对；新版删除前后核验流程仍以隔离测试为准。原生诊断控件仍为中文，收集器编辑器及管理面板提供十五种语言。

供其他 AI／程序查最新主评论、最新子回复、校验角色、发送与恢复的流程见 [AI-INTEGRATION.md](AI-INTEGRATION.md) 和 [openapi.json](openapi.json)。组件／窗口可用不等于角色全局授权，必须逐目标校验。


## 回复窗口与检测速度

普通回复窗口只保留对象、正文和一行当前服角色状态，账号／UID 详情、登录换号及重新检测放在折叠的“账号设置”中。需要登录、角色选择或核对未知写入结果时自动展开相关操作。子回复旁的“管理 / 删除”打开独立管理模式，显示删除及关闭，不混入发送表单；尚未校验或非本人时禁用删除并说明原因。

账号与角色的只读查询并行；首选线路超过约 400 毫秒仍未返回时，尝试另一条只读线路，使用先成功的响应并中止其余请求。官方业务拒绝不重复请求。此机制不用于 POST，发送与删除仍只尝试一次。

成功检测按区服在后台内存缓存最多一分钟。手动“重新检测”、官方登录窗口开启、打开登录入口或账号变化会绕过／失效缓存；失败不缓存，重启清空。发送和删除前原生程序仍重新联网核验账号及本服角色，不能用缓存代替最终校验。实际耗时取决于启动与网络，不能保证固定秒数。


## 删除后的官网核验与自我回复显示 · 2026-10-30

删除前核对目标仍属于本服角色。目标已在完整官方列表中消失时，仅清理本地旧行，不重复发删除请求。若仍存在，官方删除只请求一次，再读取原串确认不存在；短暂延迟时最多重读三轮。读回超时、分页未完成、串服或仍能查到目标均按结果未确认处理，不删除本地行、不自动重试删除。缺少新版 verified 标志的旧删除回执同样不能作为已核验成功。普通完整同步仍可根据官网最新列表更新本地内容。

自我回复保持官网显示规则：作者与对象 UID 一致时不显示“回复自己”，其他人的对象标签保留；同名但 UID 不同不能当成同一人。原始 r_user 和子回复目标 ID 不改写。账号设置使用有边框的展开／收起按钮和紧凑内容，取消重复外框与空白。


## 未确认删除的复核与关闭选项

“未确认”不是删除失败的定论。官方已受理后，原串可能短暂仍可查到，或者核对遇到网络／分页失败。新版会区分这些情况并自动跟进；确认消失后更新原尝试回执及本地旧行。达到上限或登录／归属不匹配时暂停，使用“继续核对删除结果”恢复只读检查，不重发删除。

“成功后关闭窗口”默认勾选，可取消后停留，偏好只存本浏览器。回复、删除及明确复核成功时，需本地更新也完成才关闭；未知、失败和本地保存未完成时始终保留。关闭的是弹窗，评论主页面继续显示。

## 删除自动跟进与登录窗口尺寸 · 2026-10-30

删除未确认后会自动在后台只读核对：逐步延长间隔，最多启动 8 次检查，调度窗口为 5 分钟（已开始的网络查询可稍后完成）。确认官方目标缺席后，自动清理本地回复、计数和更新标记，并刷新便签的当前回复快照；手写备注和删除历史保留。等待期间显示检查次数，关闭弹窗或主页面仍继续，后台重启会恢复剩余时限。持续存在、网络／分页异常或本地保存失败到达上限后明确暂停，可点“继续核对删除结果”；登录／归属不匹配会提前暂停。继续核对只读原目标，不再次发送删除。等待间隔不锁住同步，实际核对与同步／移除操作互斥。

新版不再停在一条“未确认”提示等用户操作。自动核对阶段显示持续状态和次数，账号设置默认收起，隐藏重复核对／重删按钮；成功时刷新列表与便签，并遵循“成功后关闭窗口”。暂停时展开原因及“继续核对删除结果”。浏览器草稿丢失时，仍可从同一目标本服角色的后端回执恢复状态。

登录窗口默认“适应窗口”，以 1280 像素桌面布局为基准，自动缩放至 50%–100%；可用下拉或 − / + 手动设置 50%–150%，再选适应恢复。顶部导航与缩放分成两行，不再把入口藏在官网横向滚动之外。官方授权子窗口仍使用其自身布局；主窗口缩放不读取或修改凭据。

## 登录提示、权限与教程

未登录、账号不匹配、无本服角色与网络失败分别显示，不能把网络错误说成密码错误。需登录时自动展开账号设置一次；手动收起后同一状态不会强行展开，按钮始终写明展开或收起。非本人回复的删除保持禁用，并显示独立权限说明；登录验证状态不足时，说明如何登录和重新检测。

七步教程的第六步定位导入关卡对应平台的登录入口；国服与外服分开，打开成功只证明窗口可见，不证明已登录。此步可以跳过，不要求输入凭据或公开发言；完成后回评论页点回复，按真实目标核验本服角色。最后一步保留浏览器翻译提示。安全检查见 [SECURITY.md](SECURITY.md)。

## 登录窗口显示与重复打开

点击登录时恢复窗口并请求置前，收到原生窗口的可见回执才提示打开成功；不再把进程启动等同于窗口显示。窗口已经打开时，再次点击恢复同平台的已有窗口，适用于被最小化或遮住的情况；不反复新开登录窗口。窗口移出当前显示器时会尝试移回可用屏幕。

Windows 可能拒绝其他程序切换前台焦点，这时页面明确提示点击任务栏的官方登录窗口。程序不保持永久置顶。启动失败或就绪超时显示失败，可再次点击恢复；窗口显示不代表登录、角色匹配或发言授权成功。更新此功能需先关闭旧官方窗口，替换完整程序后重启后台，再用 Ctrl+Shift+R 刷新页面。
