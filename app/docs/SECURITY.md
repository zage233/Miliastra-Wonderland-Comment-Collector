# 账号与回复功能安全检查 · 2026-10-30

本次针对本地登录、角色匹配、回复、删除、教程与交付文件检查。结论仅覆盖下述源码边界、隔离测试和原生自测，不代表所有第三方服务或所有运行环境都不存在漏洞。

## 检查结果与修复

| 范围 | 检查方式与结果 |
| --- | --- |
| 凭据输出 | 向模拟账号响应、角色字段、错误诊断和错误码植入凭据诱饵；公开 prepare 响应、发送回执、持久尝试文件及 HTTP 测试日志均不含诱饵。成功账号响应只取必要的账号显示名、匿名 accountKey 和本服角色字段。 |
| 错误码边界 | 本轮收紧了原来直接截断展示的 retcode：只接收规范数字码及 HTTP 4xx/5xx，不把任意诊断文字作为错误码转到页面和回执。未使用真实密码作为测试内容。 |
| 跨站请求 | 真实本地 HTTP 检查外站 Origin、字面 null Origin、跨站 Fetch 元数据、伪装 Host；账号状态、删除跟进、最新评论读取和登录／回复／删除写入均拒绝。无跨站允许响应头。伪装 Host 使用原始 HTTP 请求，避免客户端库替换该头导致测试失真。 |
| 本地文件暴露 | 静态 URL 不能读取 config/games.json、cookie.txt、reply-attempts.json、data、原生程序源码或 EXE；路径穿越 URL 同样不能读出文件。页面脚本使用固定静态白名单。 |
| 角色／区服 | 来源来自已登记关卡和真实主／子回复 ID。跨区服、错误作者、过期票据、账号切换、迟到校验及同名玩家的相关回归保留。原生写入前重新核验账号、本服角色及归属。 |
| 重复写入 | 发送／删除前持久保存 UUID 回执；未知结果不能自动换 UUID 再发。删除自动跟进只读，目标缺席后再更新本地；测试核对多轮仍最多一次模拟删除。 |

| 原生会话 | 检查固定官方 HTTPS 主机、禁用重定向、系统证书验证、固定进程路径及参数、正文经 stdin、禁用密码自动保存／自动填充。原生两个组件的自测和登录窗口的独立 WebView2 smoke 测试通过；没有用日常浏览器配置测试。 |

## 本地存储与安全边界

- 官方会话由 WebView2 保存在当前 Windows 用户的 `%LOCALAPPDATA%/MiliastraCommentCollector/LoginProbe/cn` 和 `os`，供持久登录使用。不会放入 GitHub 交付包；这不是匿名、不留会话的登录模式。
- 收集的公开评论、昵称、公开 UID、个人便签，以及发送／删除尝试回执会按功能需要保存在本地。浏览器会保存回复草稿及外观偏好。不要把整个工作目录、浏览器配置或 AppData 会话目录当作发行包分享。
- 独立的可选 `config/cookie.txt` 是用户主动创建的旧采集配置，不是登录窗口导出。发布脚本不复制当前 config；清洁校验拒绝意外个人配置文件。
- 本地接口只监听 127.0.0.1，并校验 Host、Origin、Fetch 元数据和写入的 JSON 类型。命令行与获授权的本地 AI 客户端可以不带 Origin 调用接口；它不是多用户鉴权服务器，也不隔离同一 Windows 用户下的恶意本机程序。不要将它反向代理到公网。
- 教程和应用不要求在收集器表单输入密码或验证码。登录仅在官方页面完成；打开登录窗口不代表账号或角色验证成功。教程不自动发送或删除公开内容。

测试入口：`node --test app/tests/*.test.cjs`。完整范围、测试数量和实网验证限制见 [TESTING.md](TESTING.md)。本轮对官网的公开发送／删除次数为零，HTTP 写入测试只访问隔离 mock 服务。
